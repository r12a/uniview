
Creates SVG files from a font


1. Run the font through https://www.creativefabrica.com/webfont-generator/#webfont-container

2. get the svg file output and copy it to font.svg in this directory

3. look for combining marks and add a dotted circle and x-advance

4. run python3 generateSVG.py

5. pick out the glyphs you need & copy to the c repo
